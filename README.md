# Week 1: Java Basics and Programming Elements

This week covered the foundational concepts of Java programming, setting a solid base for further development and application building.

## Topics Covered:

- **Java Fundamentals**  
  Overview of Java architecture, JVM, JDK, and basic syntax.

- **Java Programming Elements**  
  Variables, data types, operators, and type casting.

- **Java Control Flow**  
  Conditional statements (`if`, `switch`) and loops (`for`, `while`, `do-while`).

- **Java Arrays**  
  Declaration, initialization, multi-dimensional arrays, and array operations.

- **Java Methods**  
  Defining methods, parameter passing, return values, and method overloading.

- **Java Strings**  
  String creation, methods from the `String` class, string manipulation and comparison.
